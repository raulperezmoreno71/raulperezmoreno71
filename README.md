## Featured Project

### [ThreatIntel Lite](https://github.com/raulperezmoreno71/threatintel-lite)

A lightweight threat intelligence platform for analyzing URLs, domains and security-related signals.

The project combines backend development, networking and security concepts using Java, Spring Boot, React and PostgreSQL.

### [TenantGuard Lab](https://github.com/raulperezmoreno71/tenantguard-lab.git)

A multi-tenant REST API that I developed from scratch to explore secure backend development and API security.

The application implements JWT authentication, role-based access control (RBAC), and organization-level data isolation.

I built two reproducible security labs based on the OWASP API Security Top 10:

 - BOLA / IDOR: Cross-tenant unauthorized document access.

 - BFLA: Vertical privilege escalation from a read-only user to an administrator.

Both labs include intentionally vulnerable Git branches, exploitation evidence, technical documentation, secure implementations, and automated regression tests.
